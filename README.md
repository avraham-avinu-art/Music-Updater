# Pulse — מוזיקה חדשה ישר לנגן, בלי אינטרנט

<img src="store/icon.png" width="96" align="left" alt="">

אפליקציה לנגן MP3/MP4 עם אנדרואיד (או כל מכשיר אנדרואיד) שאין בו אינטרנט.
הנגן מציג פיד של השירים החדשים משלושה אתרי מוזיקה. כשהוא מחובר למחשב בכבל, המחשב מוריד את השיר, צורב בו את שם השיר, הזמר ותמונת האלבום, ומעתיק אותו לתיקיית `Music` בנגן.

<br clear="left">

## הורדה

- **האפליקציה לנגן:** [Pulse.apk](https://github.com/Xnet2/pulse/releases/latest/download/Pulse.apk)
- **התוכנה למחשב (Windows):** [Pulse-PC.zip](https://github.com/Xnet2/pulse/releases/latest/download/Pulse-PC.zip)

## התקנה

1. **בנגן:** מעתיקים את `Pulse.apk` לנגן, פותחים אותו במנהל הקבצים ומתקינים (אם מתבקש, מאשרים התקנה ממקור לא ידוע). פותחים את Pulse פעם אחת, כדי שהמחשב יזהה את הנגן.
2. **במחשב:** מחלצים את `Pulse-PC.zip` ("חלץ הכל") ולוחצים פעמיים על `install.cmd`. התוכנה רצה ברקע ומופעלת אוטומטית בכל הדלקה של המחשב. אם חסר Node.js, היא מתקינה אותו.
3. **מחברים את הנגן בכבל USB** (מצב העברת קבצים / MTP) ופותחים את Pulse. הפיד נטען תוך כמה שניות.

## מה יש בה

- פיד בסגנון רשת חברתית: פוסט לכל שיר, עם תמונת אלבום גדולה, תיאור, משך ותאריך
- המקורות: [שיר חדש](https://nigun.pages.dev/), [חדשות המוזיקה](https://newsmusic.blogspot.com/) ו[שיר בוט](https://shir-bot.ze-kal.top/)
- חיפוש בכל מאגר שיר בוט (יותר מ-10,000 שירים), גם כשהנגן לא מחובר
- הורדה בלחיצה, עם התקדמות באחוזים. כל שיר נשמר עם שם, זמר ותמונה, כך שנגן המוזיקה מציג אותם
- הורדה אוטומטית: בכל חיבור יורדים כל השירים החדשים שעוד לא בנגן (שיר שנמחק לא יורד שוב)
- בחירה אם לשמור לכרטיס הזיכרון או לזיכרון הפנימי
- ניווט מלא במקשים לטלפונים עם מקשים (כמו שיואמי), ומקש "חזור" סוגר חלוניות
- עובד עם נטפרי, ועל אנדרואיד 4.4 ומעלה

## איך זה עובד

לנגן אין אינטרנט, אז המחשב משמש לו צינור דרך הכבל:

- `bridge/` — התוכנה למחשב (Node.js). היא סורקת את הנגן דרך MTP, כותבת לתיקיית האפליקציה (`Android/data/il.offlineplayer.music/files`) את רשימת השירים, התמונות וקובץ מצב, ומבצעת הורדות שהנגן ביקש.
- `android/` — האפליקציה (Java + WebView, בלי ספריות חיצוניות). בקשה מהנגן היא קובץ ריק ששמו מכיל את הבקשה (`req-…`, `cov-…`, `cfg-…`), כדי שהמחשב יקרא אותה בלי להעתיק קבצים חזרה.

### בנייה

```powershell
powershell -ExecutionPolicy Bypass -File android\build.ps1
```

הסקריפט משתמש ב-JDK 17 וב-Android SDK שמותקנים ב-`%LOCALAPPDATA%\VODOS-build` (aapt2 → javac → d8 → zipalign → apksigner).
